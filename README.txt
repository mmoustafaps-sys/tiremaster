Tire Master - install as app
Option A (any HTTPS host: GitHub Pages, Netlify, company server):
  Upload ALL files in this folder together, open the URL in Chrome/Edge,
  click "Install App" (header button) or the install icon in the address bar.
  On iPhone: Safari > Share > Add to Home Screen.
Option B (single PC, offline): double-click Start_TireMaster.bat (needs Python),
  open http://localhost:8080 in Chrome/Edge, then Install. Keep that window open
  only while first loading; after install the app works offline from cache.
Note: opening index.html directly (file://) cannot be installed - browsers require http(s)/localhost.
